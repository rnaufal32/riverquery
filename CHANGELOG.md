## 0.1.0

- Initial release
- `createQuery` / `createQueryFamily` — cached async data fetching
- `createQueryEditable` / `createQueryEditableFamily` — queries with manual state control
- `createMutation` / `createMutationWithParam` — mutation tracking with loading/error/success states
- `createInfinityQuery` — infinite pagination
- `createStore` / `createStoreFamily` — sync state containers
- `staleTime` support with configurable cache duration
- `persist` mode for permanent caching
